COMMENT TE DONNER ACCÈS ADMIN
==============================

Le dashboard (/admin) est protégé par un champ `is_admin` dans la table
`users`. Aucun compte n'est admin par défaut. Pour te donner ce rôle,
choisis UNE des deux méthodes :

── Méthode 1 : via Tinker (recommandé) ──────────────────────────────────
cd C:\xampp1\htdocs\cinebot-ai
php artisan tinker

Puis dans le prompt Tinker qui s'ouvre :
    User::where('email', 'ajmions@gmail.com')->update(['is_admin' => true]);
    exit


── Méthode 2 : directement via phpMyAdmin / SQL ─────────────────────────
UPDATE users SET is_admin = 1 WHERE email = 'ajmions241@gmail.com';

──────────────────────────────────────────────────────────────────────────
Une fois fait, reconnecte-toi (déconnexion/connexion) puis va sur /chatbot :
une icône 📊 (speedomètre) apparaît dans la navbar à côté de ton profil,
qui mène à /admin.
